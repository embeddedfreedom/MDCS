# Furnace Control (2×2 Thermal LQI)

Model directory: `models/furnace_control/`.

## Build

| Command | Output |
|---|---|
| `make` | SIL simulator: `build/furnace_control/furnace_sim` |
| `make -f Makefile_HIL` | HIL host: `build/furnace_control/furnace_sim_hil` plus STM32F411 firmware (`MDCS_HIL.out`, `MDCS_HIL.bin`, `output.map`) in the same folder |

`make clean` (either Makefile) removes the whole `build/furnace_control/` folder, including both SIL and HIL artifacts.

## Run

Create the socat bridges first (see the repo-root `README.md` or `AGENTS.md`), then from this directory:

```bash
../../build/furnace_control/furnace_sim
```

Keys while running: `S` = enable compensator, `T` = disable, `Q` = quit.

Telemetry is the 6-value stream `<T1 T2 u1 u2 q12 Tamb>`; the 3D animation reads `/home/dipto/sim_3d` and the plotter reads `/home/dipto/sim_graph`, both at 115200 baud.

## Runtime behaviour (industrial parameters)

| Phase | What you should see |
|---|---|
| Warm-up | PWM pegged at 1.0/1.0, 75 °C reached in ≈ 1100 s (18–19 min), roughly 2.8 °C/min early on |
| Steady state | `pwm1 ≈ 0.8333`, `pwm2 ≈ 0.7454` (feedforward holding the setpoint against ambient loss) |
| `T` pressed | PWM → 0 and the slab coasts down at ≈ 2.8 °C/min from setpoint, slowing as it approaches ambient (τ ≈ 1055 s) |

`BENCH_TEST_ACCELERATED = 1` in `simulator/furnace_sim.c` divides `C1`/`C2` by 100, so the same sequence runs in seconds (75 °C in ≈ 12 s, back to ambient in ≈ 60 s) — useful for checking the law without waiting 18 minutes.

### Why the plant state is `double`

A `float` cannot represent the cooling of this plant. At 20 kHz one RK4 step changes the industrial slab by only ≈ 2.5e-6 °C, while one ULP of a `float` near 75 °C is 7.6e-6 (half an ULP = 3.8e-6). `T += dT` therefore rounded straight back to `T`, so pressing `T` left the temperature frozen instead of cooling it. Heating still worked because 36 W gives 3.6e-6 °C per step, which does clear the threshold; bench mode hid the bug because `C1 = 5` makes every step 100× larger.

`ThermalState` is now `double`, while `ThermalParams` and `compensator.c` stay `float` so the SIL law still matches the MCU law. The same note is in `simulator/furnace_sim.c` above `rk4_step()`, and the full derivation is in `docs/LQI_DERIVATION.md` §14.

## HIL verification (STM32F411)

Checked on real hardware with the firmware from `make -f Makefile_HIL`, running `build/furnace_control/furnace_sim_hil` against `/dev/ttyACM0`:

| Check | Result |
|---|---|
| Enumeration | `cafe:4001 embeddedfreedom.dev MDCS_HIL` on `/dev/ttyACM0`, user in `dialout` |
| Round trip | **0.32–0.50 ms** per host→MCU→host exchange at 921600 baud (five probes), well inside the 3 ms `poll()` timeout |
| Framing | `sync 55 AA`, valid XOR checksum, `status = 0x01` on every reply |
| Law on chip | 75/75 °C → `pwm 0.8333/0.7454` (feedforward); 76/76 → `0/0`; 25/25 and 74/74 → `1.0/1.0` |
| Bench loop | 25 → 75 °C in ≈ 11 s, holds 75.00, cools to ≈ 32 °C within 20 s of `T`; `CONNECTION ERROR` count 0 |

The MCU has no clock of its own: each received frame does `q += e * 0.001f`, so the integral assumes one host call per millisecond. The host calls at 1 kHz, which matches while the host loop keeps up; a slow host makes the integral advance more slowly in wall time, which is harmless at τ ≈ 1000 s.

## Gain derivation (Python)

`docs/furnace_lqi_design.py` solves the continuous-time ARE for the 4-state LQI plant and prints C-ready values:

```bash
python3 docs/furnace_lqi_design.py
```

It prints `IND_KX_*` / `IND_KI_*` and `PWM_SP1` / `PWM_SP2`. Copy the gains into both control-law copies:

- `compensator/compensator.c` — SIL, using the `IND_*` names
- `compensator/compensator_hil_STM32F4.c` — MCU, using `KX_*` / `KI_*`

Both C files compute `pwm_sp1` / `pwm_sp2` at init from the same parameters, so the printed `PWM_SP*` values are a consistency check rather than macros to paste.

The script is also embedded in `docs/LQI_DERIVATION.md` §16. The bench parameter set is a separate commented block in the script; the `BEN_*` gains in C are not generated by it.

See `AGENTS.md` for HIL frame format, FPU rules, and runtime notes.
